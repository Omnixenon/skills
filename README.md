# Omnixenon skills

An index of the agent skills Omnixenon publishes. Each skill lives in its own repo, named after the skill.

- [read-back](https://github.com/Omnixenon/read-back): your agent tells you what it heard before it builds anything. Install it with `npx skills add Omnixenon/read-back`.

## Claude Code

This repo is also a plugin marketplace that lists every skill above. Add it once, inside a session:

```
/plugin marketplace add Omnixenon/skills
/plugin install read-back@omnixenon
```

Each skill's own repo has install steps for Codex, Gemini CLI, Copilot and other agents.
